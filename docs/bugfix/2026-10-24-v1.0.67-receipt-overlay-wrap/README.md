# ใบรับเงินชั่วคราว (ฟอร์มสำเร็จรูป): รายการยาวล้นไปทับช่องจำนวนเงิน

- วันที่แก้: 24 ต.ค. 2569
- พบใน: v1.0.67 (มีมาตั้งแต่ v1.0.31)
- แก้ใน branch: `feat/customer-feedback-2026-10` (ระหว่างทดสอบในเบราว์เซอร์ก่อน merge PR #3)

## อาการ
หน้ารายละเอียดการชำระเงิน → "ใบเสร็จ Dot Matrix" (พิมพ์ลงฟอร์มสำเร็จรูป ไม่มีเส้นกรอบ)
ถ้าหมายเหตุ/รายละเอียดของรายการยาวเกินช่อง "รายการ" ข้อความจะยาวเป็นบรรทัดเดียวต่อไปทางขวา
ทับช่องจำนวนเงิน (ยอดชำระ / เบี้ยปรับ / หักส่วนลด) ไม่ขึ้นบรรทัดใหม่

ทดสอบด้วยหมายเหตุ 12 คำ: ข้อความยาว 274mm ในช่องกว้าง 130mm

ส่วนแบบ "มีฟอร์ม" และ A4 ไม่มีปัญหา เพราะเป็นตาราง แถวขยายลงล่างเอง

## มาจากไหน
- commit `7a00436` (10 มิ.ย. 2569) เพิ่ม overlay `temporary-receipt-bg.hbs` เข้า v1.0.31
- class `.f` ของทุกฟิลด์ตั้ง `white-space: nowrap` (ถูกสำหรับเลขที่ / วันที่ / ยอดเงิน)
  แต่ `.item-desc` ในช่องรายการไม่ได้ override ต่างจาก `.f-cust-addr` ที่ตั้ง `white-space: normal` ไว้แล้ว
- ก่อนหน้านี้แทบไม่เจอ เพราะรายการมักสั้น แต่ PR #3 ทำให้หมายเหตุตอน "จองรถ" ที่หน้าชำระเงินไปพิมพ์เป็นบรรทัดในใบเสร็จ
  พนักงานจึงพิมพ์ข้อความยาวได้ง่ายขึ้น

## วิธีแก้
- `temporary-receipt-bg.hbs`: `.item-desc { white-space: normal; }` ให้ตัดบรรทัดภายในกรอบ `.f-items` กว้าง 130mm
  (27–157mm) ไม่ย้ายตำแหน่งฟิลด์ใด ๆ
  — กรอบนี้ซ้อนกับกรอบช่องจำนวนเงิน (137–187mm) ทางแนวนอน 20mm แต่ตัวเลขชิดขวาเริ่มราว 163–175mm
  และแถวจำนวนเงินเริ่มที่ y=77mm จึงไม่ชนหมึกตัวเลข; จะทับป้ายที่พิมพ์ไว้บนฟอร์มจริงหรือไม่ ต้องพิมพ์ทดสอบ
- เทสต์ใหม่ใน `temporary-receipt-form-layout.test.ts` ตรวจว่า `.item-desc` ตัดบรรทัดได้
  และขอบขวาของช่องรายการไม่เลยขอบขวาของช่องจำนวนเงิน
